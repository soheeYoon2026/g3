# G3 개발 및 학습 현황

확인 기준: 2026-08-24  
용도: G3 작업 인수인계 및 현재 진행상황 공유

## 1. 목표

G3는 사용자가 차량 STL을 올리고 표면 형상을 변경하면서 공기역학적 변화를 빠르게 확인하는 AI 기능이다.

목표 흐름은 다음과 같다.

1. 차량 STL 입력
2. 원본 Cd/Cl 예측
3. Workbench에서 표면 제어점 이동
4. 변경 형상의 Cd/Cl과 원본 대비 ΔCd/ΔCl 예측
5. Cd 개선 가능성이 있는 표면 이동 후보 추천
6. 유망한 변형을 G2 CFD로 검증
7. 검증된 결과를 학습 데이터로 축적

G3는 G2를 대체하는 정밀 CFD가 아니라, 여러 형상 후보를 빠르게 비교하고 G2로 검증할 후보를 고르는 AI 도구를 목표로 한다.

## 2. 개발 진행 과정

G3는 다음 순서로 개발했다.

1. **기본 STL 추론 화면**
   - STL 업로드
   - G3 추론 API 연결
   - Cd/Cl 결과 표시

2. **학습 데이터 수집 백엔드**
   - G1/G2/G4 계산 결과 수집 기능 추가
   - 품질검사와 manifest 생성
   - 현재 DoMINO 학습은 정제된 G2 자동차 데이터를 중심으로 사용

3. **자동차용 AI 모델 학습**
   - 초기 PointNet 계열 모델 시험
   - 자동차용 DoMINO decoder fine-tuning으로 전환
   - `decoder-30epoch.pt`를 현재 추론 모델로 연결

4. **G3 전용 Workbench**
   - 기존 Workbench 렌더링과 GLB/ProxyMesh 재사용
   - 최대 72개 표면 제어점 추가
   - 국소 표면 변형, 좌우 대칭, Undo, Reset 구현
   - 여러 메시 조각을 전체 차량 STL로 내보내도록 구성

5. **메시 준비와 반복 추론**
   - 화면 표시용 GLB와 AI 입력용 STL 분리
   - 메시 캐시 토큰 추가
   - G3_TEST에서 GPU 모델 상주 실행

6. **프로젝트 및 비동기 실행 구조**
   - G3 프로젝트별 STL과 실행 결과 관리
   - 프로젝트별 AI 실행 이력 저장
   - Django와 Celery를 통한 비동기 추론 연결

   `프론트 → Django → Celery → G3 GPU 서비스 → 결과 저장 → 프론트 조회`

7. **원본과 변형 결과 비교**
   - 원본 Cd/Cl을 baseline으로 저장
   - 편집 형상의 Cd/Cl 실행
   - ΔCd/ΔCl 표시

8. **표면 이동 추천**
   - Workbench 제어점별 이동 후보 생성
   - AI로 후보별 Cd/Cl 예측
   - 예상 Cd 기준 후보 정렬
   - 선택한 후보를 Workbench 표면에 적용

9. **G2 검증 데이터 생성 및 추가 학습 실험**
   - 추천 변형 STL을 G2로 계산
   - 원본과 변형의 실제 ΔCd 생성
   - Ridge, ΔCd challenger, 양방향 변형 및 추천 변형 학습 비교
   - 검증되지 않은 실험 모델은 현재 서비스에 미적용

10. **자동 수집과 관리자 화면**
    - 매일 자정 G2 신규 결과 수집
    - 중복·품질검사와 데이터 분류
    - 수집·정제·학습 상태 대시보드 구현

프론트, Workbench, Django 및 관리자 화면의 G3 코드는 `temp/g3-workbench-transfer` 브랜치에 정리했다. G3_TEST의 일부 실험 코드는 아직 별도 정리가 필요하다.

## 3. 지금까지의 학습

### 초기 PointNet 계열 실험

초기 G3-v2에서는 작은 PointNet 계열 모델을 학습했다.

- G2 269건: 압력장·속도장·Cd·Cl 학습
- G1 Drag 38건, G1 Lift 13건, G4 17건: 계수 보조학습
- 마지막 기록의 G2 Validation Cd MAE: 약 `0.1015`
- 마지막 기록의 G2 Validation Cl MAE: 약 `0.0297`

이 모델은 현재 사용자 추론에 사용하지 않는다.

### 자동차용 DoMINO 계열 학습

차량 형상과 국소 변형을 다루기 위해 PhysicsNeMo-CFD의 자동차용 DoMINO 계열로 전환했다. 정제된 G2 자동차 데이터를 중심으로 decoder fine-tuning을 수행했다.

현재 사용자 추론에 연결된 체크포인트:

`/home/ubuntu/g3-v2/var/domino-automotive-runs/decoder-30epoch.pt`

저장된 평가 결과:

| 평가 | Cd MAE | Cl MAE |
|---|---:|---:|
| Fine-tune Validation | 0.0567 | 0.0032 |
| Fine-tune Test | 0.0219 | 0.0907 |


### 국소 변형 ΔCd 실험

이후 목표를 완성된 STL의 Cd/Cl 예측에서 표면 변형에 따른 `ΔCd` 예측까지 확장했다.

`ΔCd = 변형 형상의 G2 Cd - 원본 형상의 G2 Cd`

확인된 실험 묶음:

| 실험 | 목적 | 규모 |
|---|---|---:|
| 초기 Cd-only 변형 | 제어점 변형과 ΔCd 연결 확인 | 유효 27건 |
| Ridge 보정 실험 | 안쪽·바깥쪽 변형 보강 | 39건 |
| 양방향 변형 | 이동 방향에 따른 차이 학습 | 57건 |
| 추천 변형 | 추천 후보와 G2 결과 연결 | 84건 |

이 네 묶음은 하나의 데이터셋을 `27 → 39 → 57 → 84건`으로 누적한 단일 과정이 아니다. 목적과 manifest가 다른 실험이며 일부 데이터가 겹칠 수 있으므로 건수를 합산하면 안 된다.

실험 결과 요약:

- Ridge 보정기는 ΔCd MAE를 아주 조금 줄였지만 방향 정확도는 50%였다.
- 첫 ΔCd challenger는 ΔCd는 개선했지만 절대 Cd/Cl 성능이 크게 악화됐다.
- 양방향 57건 실험은 Test 일부가 좋아졌지만 Validation 방향 정확도가 악화됐다.
- 추천 변형 84건 실험은 개선 폭이 거의 없고 방향 정확도도 50%였다.

따라서 추가 실험 모델은 현재 서비스 모델로 적용하지 않았다.

## 4. 현재 모델 검증 결과

### NISMO 원본 비교

현재 모델의 NISMO 원본 결과:

- AI Cd: `0.4723`
- AI Cl: `-0.1775`
- G2 기준 Cd: `0.3207`
- Cd 차이: 약 `0.1516`
- 속도: `30 m/s`
- 공기 밀도: `1.225 kg/m³`
- Aref: `3.1201 m²`
- 진행 방향: `+X`

저장된 Test Cd MAE는 `0.0219`였지만 NISMO 사례의 오차는 훨씬 컸다. 따라서 현재 모델이 새로운 차량에도 동일한 정확도를 낸다고 판단할 수 없다.

NISMO 한 대에 맞춘 상수 보정은 다른 차량의 예측까지 변경하므로 적용하지 않았다.

또한 G2 `0.3207`이 정확히 어느 step의 값인지 최종 확인이 필요하다.

## 5. 현재 구현된 기능

- G3 프로젝트에서 STL 선택 및 업로드
- Workbench 기반 차량 표시
- 최대 72개 표면 제어점 편집
- 좌우 대칭 변형
- Undo 및 Reset
- 원본 Cd/Cl 실행 및 기준값 저장
- 변경 형상의 Cd/Cl 및 ΔCd/ΔCl 비교
- 표면 이동 후보 추천
- 추천 후보를 Workbench 형상에 적용
- 프로젝트별 AI 실행 이력 저장
- 메시 캐시를 이용한 반복 STL 전송 감소
- 관리자 화면에서 수집·정제·학습 상태 확인

프론트 요청은 Django에 실행을 등록하고, Celery가 G3 GPU 서비스를 호출한 뒤 프론트가 결과를 조회하는 비동기 구조다.

## 6. 데이터 수집 현황

현재 DoMINO 자동 수집은 G2 결과가 저장되는 다음 버킷을 검사한다.

- `aoxlabs-stage-static`
- `aoxlabs-prod-static`

매일 자정(Asia/Seoul)에 systemd timer로 실행된다.

최신 확인 결과:

- 검사 시도: 342건
- 채택: 209건
- 제외: 133건
- 고유 그룹: 199개
- 최신 실행 신규 채택: 0건
- 신규 데이터가 5건 미만이어서 자동 학습 생략

별도 재검사 데이터에는 265건이 채택되어 있다. 209건과 265건은 서로 다른 검사 산출물이므로 합산하지 않는다.

검토된 자동차 subset 분류:

- Train: 54건
- Validation: 9건
- Test: 8건
- 자동차 외 형상 제외: 62건

이 숫자는 전체 265건의 완전한 분할이 아니라 검토된 subset의 결과다.

## 7. 현재 서비스 상태

- 서버: G3_TEST
- GPU: NVIDIA RTX PRO 6000 Blackwell Server Edition
- 상주 AI 서비스: 실행 중
- 현재 모델: `decoder-30epoch.pt`

G3_TEST 저장공간은 확인 당시 96 GB 중 84 GB를 사용해 약 13 GB가 남아 있었다. 자동 수집의 최소 여유 기준 10 GB에 가까우므로 정리가 필요하다.

## 9. 현재 판단

현재까지 완료된 부분:

- STL 입력부터 표면 편집, Cd/Cl 추론과 변화 비교까지 연결
- 추천 후보 생성 및 Workbench 적용
- G2 결과 자동 수집
- 변형 G2 데이터로 여러 ΔCd 학습 방법 시험

아직 해결되지 않은 부분:

- NISMO에서 확인된 큰 절대 Cd 오차
- 새로운 차량 계열에 대한 일반화 검증
- 추천 변형의 ΔCd 방향 정확도
- G2 원본과 AI 입력의 완전 동일성 검증
- 실험 데이터 간 중복과 체크포인트 계보 정리
- G3_TEST 미커밋 코드 정리

현재 G3는 차량 형상을 빠르게 비교·탐색하는 AI 실험 시스템이다. 일부 분할에서는 좋은 MAE를 보였지만 범용 차량 공력 예측 모델로 검증 완료된 상태는 아니다.
